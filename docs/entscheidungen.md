# Entscheidungen

Kurze Einträge: Datum, Entscheidung, Grund. Neueste oben. Offene Fragen gehören als Issue mit Label `frage` auf GitHub.

## 18.11.2026 – Projektstart

| Thema                    | Entscheidung                                                                                                                                                                                                                                                                                         | Grund                                                                                                                                                                                                                               |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Abgrenzung               | EDKN Technik ist eigenständig, kein Modul im SMS-Portal. Technischer Zustand → EDKN Technik, Sicherheitsereignisse → SMS.                                                                                                                                                                            | Klare Zuständigkeit, schlankes Tool. Grenze wird mit dem SMS-Verantwortlichen abgestimmt.                                                                                                                                           |
| Login Prototyp           | E-Mail + Passwort mit Freigabe durch den Admin. Vereinsflieger-Login später (`profiles.vf_uid` schon anlegen).                                                                                                                                                                                       | Sofort startklar, kein App-Key nötig.                                                                                                                                                                                               |
| Sichtbarkeit (vorläufig) | Mittelweg aus `docs/handoff.md` Abschnitt 4. Regeln nur zentral in RLS/Views.                                                                                                                                                                                                                        | Fachlich noch offen zwischen Werkstattleiter und Projektleitung.                                                                                                                                                                    |
| Kat 1 und Sperre         | Eine offene Kat-1-Meldung macht das Flugzeug rot (berechnet in der View). Beim Erledigen eines Kat-1-Punkts bestätigt der Wart ausdrücklich „Flugzeug ist wieder flugklar“, das steht im Verlauf. Die **manuelle Sperre** ist ein eigener Schalter am Flugzeug, z. B. für „Jahresnachprüfung läuft“. | Kein vergessenes Entsperren, aber trotzdem eine bewusste Freigabe.                                                                                                                                                                  |
| Umstufen                 | Ein Wart darf eine Einstufung später ändern (z. B. Kat 2 → Kat 1), mit Eintrag im Verlauf.                                                                                                                                                                                                           | Neue Erkenntnisse in der Werkstatt.                                                                                                                                                                                                 |
| Melder                   | Nach dem Absenden kann der Melder seine Meldung nicht bearbeiten oder löschen, aber einen Nachtrag als Kommentar schreiben.                                                                                                                                                                          | Verlauf bleibt nachvollziehbar.                                                                                                                                                                                                     |
| Namen                    | Piloten sehen die Namen der Warte („gesperrt von …“), aber nicht, wer fremde Meldungen abgegeben hat.                                                                                                                                                                                                | Datensparsam, passt zur Sorge des Werkstattleiters.                                                                                                                                                                                 |
| Doku                     | In `docs/` stehen Rollen statt Namen. Mails und persönliche Daten kommen nicht ins Repo.                                                                                                                                                                                                             | Repo wird mit mehreren Leuten geteilt, evtl. später in eine Vereins-Organisation verschoben.                                                                                                                                        |
| Sprache                  | Fachbegriffe deutsch wie im Handoff (`rolle`, `freigabe`, `kategorie`, `pilotenhinweis` …), technische Namen englisch (`ReportForm`, `useAircraftList`). Commits (Conventional Commits) und Code-Kommentare auf Deutsch.                                                                             | Einheitlich, nah an der Fachsprache.                                                                                                                                                                                                |
| Paketmanager             | npm                                                                                                                                                                                                                                                                                                  | Ist überall vorhanden, keine Extra-Installation.                                                                                                                                                                                    |
| Workflow                 | Jeder Schritt wird committet, gepusht und als PR geprüft. Das Okay der Projektleitung heißt „weiter mit dem nächsten Schritt“.                                                                                                                                                                       | Diff auf GitHub sichtbar.                                                                                                                                                                                                           |
| RLS-Tests                | Laufen zusätzlich in der CI (ab Schritt 2).                                                                                                                                                                                                                                                          | Sicherheitsregeln werden bei jedem PR echt geprüft.                                                                                                                                                                                 |
| Hosting                  | **Cloudflare Pages** statt Vercel.                                                                                                                                                                                                                                                                   | Der Vercel-Gratis-Tarif baut bei privaten Repos keine Deployments von Commits anderer Personen (keine Zusammenarbeit im Hobby-Tarif). Cloudflare Pages: kostenlos, private Repos, Preview-Link pro Branch/PR, 500 Builds pro Monat. |
| Linter                   | TypeScript 7 mit **oxlint** statt ESLint, Formatierung mit Prettier.                                                                                                                                                                                                                                 | Das offizielle Vite-Template nutzt TS 7 + oxlint. typescript-eslint unterstützt TS 7 noch nicht.                                                                                                                                    |
